Architecture

The signal pipeline

Audio capture → STFT + ERB filterbank → DeepFilterNet3 → adaptive post-filter → clear audio.

Audio Capture
STFT + ERB Filterbank
DeepFilterNet3
Adaptive Post-Filter
Clear Audio

Pre-processing

Resampling, pre-emphasis, framing, windowing and normalization.

Analysis

STFT with perceptual ERB features (log-power) for compact, speech-relevant input.

DeepFilterNet3

ERB encoder, temporal model and decoder predict a mask plus deep-filter coefficients.

Post-processing

Apply estimated filter to the spectrum, then inverse STFT to reconstruct time-domain speech.
